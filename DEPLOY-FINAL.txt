OTPKU FINAL REVISION — 08 AUG 2026

ZIP ini hanya berisi file project yang berubah pada sesi revisi hari ini.
Tidak berisi .env, app.env, credential, vendor, node_modules, database, backup,
atau file project lain yang tidak terkait.

GitHub / repository:
1. Ekstrak isi ZIP ke ROOT repository OTPKU (merge/replace file yang sama).
2. Review `git diff`.
3. Commit dan push seperti deployment sebelumnya.

Setelah deploy berhasil:
- Migration GitHub OAuth akan dijalankan oleh deployer bila migration terdeteksi.
- Asset Vite akan dibuild ulang karena package.json/resources/js/resources/css berubah.
- Jalankan sinkron katalog sekali agar harga yang tampil langsung memakai data provider terbaru:

  docker exec kodeotp-app_green-1 php artisan otp:catalog-sync

  Jika slot aktif ternyata blue, ganti kodeotp-app_green-1 menjadi kodeotp-app_blue-1.

- Lalu clear cache jika diperlukan:

  docker exec <container-app-aktif> php artisan optimize:clear

GitHub OAuth tetap memakai environment server /opt/kodeotp/app.env:
GITHUB_CLIENT_ID=...
GITHUB_CLIENT_SECRET=...
GITHUB_REDIRECT_URI=https://otpku.jagoanproject.com/auth/github/callback

Perbaikan harga final:
- Harga provider dipakai 1:1 sebagai biaya provider.
- Markup 10%: provider Rp 1.000 => harga user Rp 1.100 (sebelum/menurut aturan pembulatan yang dipilih).
- Parser katalog memprioritaskan sellPrice.
- autoSearchServer dimatikan agar provider tidak otomatis pindah ke priceId/server lain yang lebih mahal dari harga yang ditampilkan.

Perbaikan lain dalam ZIP final:
- Saldo administrator = saldo provider.
- GitHub OAuth.
- UI desktop/mobile header/nav.
- 404 custom + redirect 7 detik.
- CSP Alpine build + auto polling order.
- Tombol aksi order, cancel/refund, self-healing queue.
- Koreksi provider order ID vs activation ID.
- Sitemap short_open_tag fix.
- Deploy mempertahankan hashed Vite asset lama dan menyimpan KODEOTP_IMAGE agar docker compose manual tidak mencoba pull kodeotp-app:latest.
